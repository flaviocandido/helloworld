## Guia de Tamanhos

`index.html` é um app web (sem dependências) que pede as medidas (altura, busto,
cintura, quadril), mostra graficamente onde cada uma cai na tabela de tamanhos
(4Y–14Y) e sugere o tamanho a comprar. Basta abrir o arquivo no navegador.

Regra da sugestão: cada medida indica um tamanho; se ficar entre duas faixas,
arredonda para o maior. O tamanho sugerido é o maior entre as medidas, para a
roupa não ficar apertada.
